The folder contains various .py files, which are described below.

1) GetprobsMAR.ipynb:
	generates Transition probability matrices among events in the alphabet. Size of the alphabet 'M', is the only parameter of these codes and given 'M' the codes generate a dense and a sparse matrix which represent a a dense and a sparse transition probability matrix of an irreducible markov chain with 'M' events. While generating sparse matrix, the parameter "n_clus" (0 < n_clus <= M) determines the sparsity. High n_clus leads to higher sparsity. The output would be two .npy files of the name "Markov_M_<M>_probs_dense.npy" and "Markov_M_<size of alphabet>_probs_sparse_n_clus_<n_clus>.npy" containing the numpy transition matrix.




2) DataGen_NO_serial.ipynb:
	This contains the code for generating datastream of events, given the following parameters

M = Size of the alphabet (No of events)
N_emb = No of serial episodes to be embedded
N = Length of serial episodes to be embedded
T = Desired datastream length
p = geometric parameter that determined the gap between end of an occurrence and the start of the next occurrence of embedded episodes 
eta = geometric parameter that determined the gap between two successive events of an occurrence of embedded episode.
specs = 'equal'    # This would make each row of the probability transition matrix among event uniform
specs = 'dense'    # This would load the saved dense probability transition matrix generated by GetprobsMAR.ipynb
specs = 'sparse'/'sparse_n_clus<n_clus>'     # This would load the saved sparse probability transition matrix generated by GetprobsMAR.ipynb

The output is a .txt file containing the datastream named "Datastream_M_<M>_n_<T>_emb_<N_emb>_N_<N>_p_<p>_eta_<eta>_probs_<specs>.txt" if episodes are embedded and "Datastream_M_<M>_n_<T>_probs_<specs>.txt" if no episodes are embedded.




3) GraphGen_NO_MAR_MinDFA.py:

This code generates minimal DFA (for Markov Data) for a given episode and does the quality of approximation.

The inputs used in the code are

episodes: contains various episodes (with one maximal event) of various sizes.

M: size of alphabet (no of events)

specs = 'equal'    # This would make each row of the probability transition matrix among event uniform
specs = 'dense'    # This would load the saved dense probability transition matrix generated by GetprobsMAR.py
specs = 'sparse'/'sparse_n_clus<n_clus>'     # This would load the saved sparse probability transition matrix generated by GetprobsMAR.py

T_list : Contains list of values each representing the desired length of the datastream

Output of this file is plots containing the quality of approximation of given episodes, under Data of lengths specified in T_list, size of events 'M' and Transition probability matrix of events given by 'specs'.





4) ISE_DFS_NO_SS_NO_MAR_Ren.py (Our method)

This code takes a datastream, mines out frequent closed episodes of that datastream under expriry constraint 'T_x' and frequency threshold 'F_th'. It then calculated the Statistical significance threshold for each of these frequent closed episodes under Markov Null and finally provides those episodes which qualified under statistical significance threshold.

5) ISE_DFS_NO_SS_NO_IID_Ren.py (Baseline)

This code takes a datastream, mines out frequent closed episodes of that datastream under expriry constraint 'T_x' and frequency threshold 'F_th'. It then calculated the Statistical significance threshold for each of these frequent closed episodes under IID Null and finally provides those episodes which qualified under statistical significance threshold.
